# 《重返未来：1999》语音及文本提取工具

从APK中取得指定角色的英文语音，解码为WAV并关联剧情文本

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `collect_resources.py` | 通过ADB拉取配置、剧情Bundle和热更新BNK；可同时从APK提取内置BNK |
| `decrypt_datacfg.py` | 解密`datacfg_*.dat`，导出语音配置表 |
| `extract_story.py` | 从`configs/story` Unity Bundle导出`json_story_step_*.json` |
| `extract_audio.py` | 解析Wwise BNK，按语音配置提取WEM |
| `map_voice_text.py` | 按`voice_id`关联WAV、事件、BNK、角色和英文文本，并生成GPT-SoVITS清单 |

## 环境要求

1. Python 3.10或更新
2. 确保`adb`可用
3. 能正确连接到设备模拟器，例如：

```powershell
adb connect 127.0.0.1:7555
adb devices
```

4. 安装Python依赖：

```powershell
python -m pip install -r tool/requirements.txt
```

5. 准备 `vgmstream-cli`


## 运行

在项目根目录执行：

```powershell
python tool/run_pipeline.py `
  --result result `
  --serial 127.0.0.1:7555 `
  --package com.mover.twcfwl1999 `
  --hero 5043 `
  --language en `
  --apk D:\path\to\twcfwl1999.apk `
  --vgmstream D:\path\to\vgmstream\test.exe
```

## 分步执行

### 获取资源

```powershell
python tool/collect_resources.py `
  --output result/source `
  --serial 127.0.0.1:7555 `
  --package com.mover.twcfwl1999 `
  --hero 5043 `
  --language en `
  --apk D:\path\to\twcfwl1999.apk
```

模拟器资源根目录通常为：

```text
/storage/emulated/0/Android/data/com.mover.twcfwl1999/files/ResLib/Android
```

### 解密

```powershell
python tool/decrypt_datacfg.py result/source/configs result/config
```

参数由`libil2cpp.so`和`global-metadata.dat`静态分析得到：

```text
格式：48字节签名头 + AES
算法：AES-256-CBC
填充：PKCS#7
Key：@_#*&Reverse2806，右侧补空格到32字节
IV：!_#@2022_Skyfly)，右侧补空格到16字节
```

输出的 `result/config/tables` 中包含：

```text
voice_id -> Wwise Event名称 -> BNK名称
```

### 导出剧情文本

```powershell
python tool/extract_story.py result/source result/story
```

### 提取并解码音频

```powershell
python tool/extract_audio.py `
  result/source `
  result/config/tables `
  result/WAV `
  --hero 5043 `
  --vgmstream D:\path\to\vgmstream\test.exe
```

解码命令固定使用：

```text
vgmstream -i -o output.wav input.wem
```

`-i` 忽略Wwise循环信息

### 关联文本

```powershell
python tool/map_voice_text.py `
  result/WAV/audio_index.jsonl `
  result/story `
  result/mapping `
  --list-prefix /data/admin4/dataset/hero5043/WAV/
```

主要输出：

```text
result/WAV/*.wav
result/WAV/audio_index.jsonl
result/mapping/mapping.jsonl
result/mapping/mapping.csv
result/mapping/unmatched.csv
result/mapping/gpt-sovits.list
result/mapping/summary.json
```

GPT-SoVITS清单只包含`matched_unique_english`，格式为：

```text
/data/admin4/dataset/hero5043/WAV/xxx.wav|Vertin|en|English text
```

## 版本与完整性注意事项

- 优先使用国际服发布的apk，简中版有大量英文剧情语音缺失
- 若游戏升级后密钥或格式变化，应重新使用Il2CppDumper配合反汇编检查`GameConfig.get_AESPassword`、`GameConfig.get_AESKeyVector`、`FileHelper.RsaVerity`和`MD5Util.AESDecryptByte`
