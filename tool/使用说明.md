# 《重返未来：1999》语音及文本提取工具

从APK中取得指定角色的英文语音，解码为WAV并关联剧情文本

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `collect_resources.py` | 通过ADB拉取配置、剧情 Bundle 和热更新 BNK；可同时从 APK 提取内置 BNK。 |
| `decrypt_datacfg.py` | 解密 `datacfg_*.dat`，导出语音配置表。 |
| `extract_story.py` | 从 `configs/story` Unity Bundle 导出 `json_story_step_*.json`。 |
| `extract_audio.py` | 解析 Wwise BNK，按语音配置提取 WEM，并使用 `vgmstream -i` 解码为不循环 WAV。 |
| `map_voice_text.py` | 按 `voice_id` 关联 WAV、事件、BNK、角色和英文文本，并生成 GPT-SoVITS 清单。 |
| `run_pipeline.py` | 按顺序执行上述完整流程。 |

## 环境要求

1. Python 3.10 或更新版本。
2. Android Platform Tools，确保 `adb` 可从命令行调用。
3. MuMu 已开启 ADB，并能连接到设备，例如：

```powershell
adb connect 127.0.0.1:7555
adb devices
```

4. 安装 Python 依赖：

```powershell
python -m pip install -r tool/requirements.txt
```

5. 准备 `vgmstream-cli`。Windows 旧版工具通常名为 `test.exe`，并要求相关 DLL 与它位于同一目录。
6. 推荐提供与模拟器安装版本一致的 APK。APK 内通常包含大量基础英文 BNK，模拟器 `ResLib` 主要提供热更新或增量 BNK；二者合并才能得到较完整的语音集。

## 一键运行

在项目根目录执行：

```powershell
python tool/run_pipeline.py `
  --result result `
  --serial 127.0.0.1:7555 `
  --package com.mover.twcfwl1999 `
  --hero 5043 `
  --language en `
  --apk D:\path\to\twcfwl1999.apk `
  --vgmstream D:\path\to\vgmstream\test.exe
```

如果 `result/source` 已经包含此前拉取的快照，可跳过 ADB 拉取：

```powershell
python tool/run_pipeline.py `
  --result result `
  --skip-collect `
  --hero 5043 `
  --vgmstream D:\path\to\vgmstream\test.exe
```

## 分步执行

### 1. 获取模拟器和 APK 资源

```powershell
python tool/collect_resources.py `
  --output result/source `
  --serial 127.0.0.1:7555 `
  --package com.mover.twcfwl1999 `
  --hero 5043 `
  --language en `
  --apk D:\path\to\twcfwl1999.apk
```

模拟器资源根目录为：

```text
/storage/emulated/0/Android/data/com.mover.twcfwl1999/files/ResLib/Android
```

脚本拉取：

- `configs/allmanifest.dat`、`resinfo.dat`、`datacfg_*.dat`；
- `configs/story` 对应的哈希 Bundle；
- `audios/Android/en/*5043*.bnk`；
- APK 中的内置英文 `*5043*.bnk`。

### 2. 解密配置

```powershell
python tool/decrypt_datacfg.py result/source/configs result/config
```

客户端解密参数由 `libil2cpp.so` 和 `global-metadata.dat` 静态分析得到：

```text
格式：48 字节签名头 + AES 密文
算法：AES-256-CBC
填充：PKCS#7
Key：@_#*&Reverse2806，右侧补空格到 32 字节
IV：!_#@2022_Skyfly)，右侧补空格到 16 字节
```

输出的 `result/config/tables` 中包含：

```text
voice_id -> Wwise Event 名称 -> BNK 名称
```

### 3. 导出当前剧情文本

```powershell
python tool/extract_story.py result/source result/story
```

脚本根据 `allmanifest.dat` 定位 `configs/story`，用 `resinfo.dat` 校验 Bundle，再通过 UnityPy 导出全部 `json_story_step_*.json`。英文文本位于语言槽位 2。

### 4. 提取并解码音频

```powershell
python tool/extract_audio.py `
  result/source `
  result/config/tables `
  result/WAV `
  --hero 5043 `
  --vgmstream D:\path\to\vgmstream\test.exe
```

关联链路为：

```text
voice_id
-> Event 名称
-> FNV-1 32 位 Event ID
-> HIRC Event
-> Action
-> Sound
-> DIDX media_id / DATA WEM
-> WAV
```

解码命令固定使用：

```text
vgmstream -i -o output.wav input.wem
```

`-i` 忽略 Wwise 循环信息，只输出一次源媒体，避免默认循环次数导致语音片段重复。

### 5. 关联文本并生成清单

```powershell
python tool/map_voice_text.py `
  result/WAV/audio_index.jsonl `
  result/story `
  result/mapping `
  --list-prefix /data/admin4/dataset/hero5043/WAV/
```

主要输出：

```text
result/WAV/*.wav
result/WAV/audio_index.jsonl
result/mapping/mapping.jsonl
result/mapping/mapping.csv
result/mapping/unmatched.csv
result/mapping/gpt-sovits.list
result/mapping/summary.json
```

GPT-SoVITS 清单只包含 `matched_unique_english`，格式为：

```text
/data/admin4/dataset/hero5043/WAV/xxx.wav|Vertin|en|English text
```

## 映射状态

- `matched_unique_english`：唯一英文文本
- `no_story_step_for_voice`：音频配置存在，但剧情步骤未引用该 `voice_id`。
- `empty_english_in_story`：步骤存在但英文槽为空。
- `nonverbal_text`：只有省略号、停顿等非语言内容。
- `conflicting_english_texts`：同一WAV对应多个不同英文文本，保留。

## 版本与完整性注意事项

- 优先使用国际服发布的apk，简中版有大量英文剧情语音缺失
- APK、模拟器 `ResLib`、`datacfg` 和剧情 Bundle 应来自同一客户端版本。
- `collection.json`、`verification.json`、`provenance.json` 保存来源和哈希，用于排查版本混用。
- 离线配置解密验证了 AES 块、PKCS#7 填充和 JSON 结构，但没有验证前 48 字节的 RSA 签名。
- 若游戏升级后密钥或格式变化，应重新使用 Il2CppDumper 配合反汇编检查 `GameConfig.get_AESPassword`、`GameConfig.get_AESKeyVector`、`FileHelper.RsaVerity` 和 `MD5Util.AESDecryptByte`。
